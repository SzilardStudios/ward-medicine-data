# Ward Drug Lookup – medicine data updates

Test data for the Ward Drug Lookup demo app. Not for clinical use.

Contains medicine names, strengths, forms, brand names and product barcodes taken from the NHS dm+d
(Dictionary of Medicines and Devices), supplied by NHS Business Services Authority via NHS TRUD.

Contains public sector information licensed under the Open Government Licence v3.0.
https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/

`manifest.json` says which data version is the newest. The app downloads the file it names, checks it, and only then uses it.
